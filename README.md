DocSensei Backend

DocSensei is an AI-powered document intelligence backend designed to simplify document processing and enable intelligent information retrieval.

✨ Features

- 📄 Document processing and information extraction
- 🤖 AI-powered question answering
- 🔍 Intelligent document search and retrieval
- ⚡ RESTful API integration

🛠️ Tech Stack

The project uses modern backend technologies and AI integrations to deliver efficient document processing and retrieval.

🚀 Getting Started

git clone https://github.com/bMonad/DocSenseiBackend.git
cd DocSenseiBackend

Install the required dependencies and configure the environment variables according to the project setup.
